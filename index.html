    Spesifikasi Teknis Tugas PAW

    Rincian implementasi 5 modul pengembangan yang diterapkan pada repositori ini.

    1. 1. Aplikasi Web Pengelola Tugas

      Menampilkan daftar tugas kuliah aktif, formulir tambah tugas baru, mode edit tugas yang ada, tombol hapus, serta perubahan status antara Belum Selesai dan Selesai dalam antarmuka responsif.

    2. 2. Manajemen Versi Git dan GitHub

      Repositori terhubung ke riffq1122/paw-personal-web dengan riwayat minimal 5 commit terstruktur, lebih dari 2 branch fitur, proses merge ke branch main, simulasi penyelesaian merge conflict, serta branch khusus untuk Pull Request.

    3. 3. Pengelolaan Paket npm dan Vite

      Proyek dibangun memakai bundler Vite dengan pengelolaan paket melalui npm, pemisahan dependencies vs devDependencies, standar semantic versioning, serta script dev, build, dan preview di package.json.

    4. 4. Implementasi TypeScript

      Kode sumber src/main.ts menerapkan primitive types (string, number, boolean), array bertipe, interface (TaskItem, AppEnvironmentConfig), type alias dan union type (TaskStatus, TabId, TaskFilter), serta fungsi generics sederhana (readStorage<T>, writeStorage<T>, filterItems<T>).

    5. 5. Environment Variables

      Berkas .env menyimpan konfigurasi non-rahasia (VITE_APP_NAME, VITE_APP_VERSION), didokumentasikan pada .env.example, diberi tipe pada src/vite-env.d.ts, dan dilindungi oleh .gitignore agar kredensial tidak terunggah ke GitHub.
